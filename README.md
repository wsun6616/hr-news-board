# HR与投资资讯在线看板（免费版）

这是一个零现金成本的静态网站项目，用于查看 HR 实务资讯、按日期回看历史内容，并聚合公开市场投资资讯。

## 一、当前功能

- HR 板块固定展示最新 **100 条**实务资讯
- 按发布时间倒序排列，支持分类筛选和关键词搜索
- 历史资讯按日期保存，可通过日期下拉框回看
- 投资板块展示公开行情快照和市场资讯
- 每小时由 GitHub Actions 自动抓取并更新
- 页面每 5 分钟自动检查一次数据文件
- 支持已读、收藏、原文跳转；这些状态仅保存在当前浏览器
- 不依赖付费服务器或付费数据库
- 本地可直接双击 `双击打开-100条.html`，该文件已内嵌 HR 和投资数据

## 二、数据来源

- HR 主数据源：湖北省人社厅工作动态
- HR 备用数据源：人力资源和社会保障部 RSS
- 投资资讯：中新网财经 RSS，经关键词筛选和分类
- 行情快照：腾讯行情、新浪汇率等公开接口

投资板块仅呈现公开资讯、行情摘要和风险提示，不提供个性化买卖指令，也不构成投资建议。

## 四、免费部署步骤

1. 新建 Public GitHub 仓库，例如 `hr-news-board`。
2. 上传本文件夹内全部内容，保持目录结构不变。
3. 在仓库 Settings → Pages 中，选择 Deploy from a branch。
4. Branch 选择 `main`，目录选择 `/root`。
5. 等待 GitHub Pages 构建完成，获得 `https://用户名.github.io/hr-news-board/` 地址。
6. 在 Actions 中确认 `Update HR news` 工作流可用；之后会按计划自动运行。

## 五、免费方案边界

1. GitHub 免费服务不承诺付费服务器级 SLA，定时任务可能延迟。
2. 若来源网站临时不可用，系统保留已有历史数据，不编造内容。
3. 若某天定时任务未成功运行，该日期可能没有历史文件。
4. 行情为定时更新，不是交易所级实时行情。
5. 公开仓库不应写入个人账户、持仓、金额、聊天记录或其他隐私信息。
6. 若以后需要账号体系、全文检索、实时行情、多人协同或服务保障，再考虑付费服务器和数据库。

## 六、日常使用建议

- 处理员工问题时，优先查看“劳动争议案例”和“社保医保实务”。
- 涉及工伤、试用期、竞业限制、欠薪、社保公积金时，点击原文核对官方口径。
- 需要回看此前内容时，使用“历史资讯”按日期查询。
- 查看投资内容时，把它作为公开信息汇总，独立判断风险，不直接依据页面作出买卖决策。
